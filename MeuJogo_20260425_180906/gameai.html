Sistemas do Jogo

⚔️ Combate por Turnos

Sistema completo com ATK, DEF, HP, MP. Ações: atacar, habilidade especial, usar poção, fugir. Inimigos com drops e recompensas.

🗺️ Exploração

Salas com eventos aleatórios (armadilhas, tesouros, poderes), itens para coletar e múltiplas rotas.

🧩 Puzzles

Enigmas com múltipla escolha, dicas, 2 tentativas e penalidade por erro. Bônus por resolver todos.

🏪 Loja

Compra de poções, armas, escudos e elixires com Gold. Itens aplicam efeitos imediatos no personagem.

📈 Progressão

Sistema de XP e Level Up com aumento automático de HP, MP, ATK e DEF. XP necessário cresce 1.5× por nível.

🎒 Inventário

Coleta e uso de itens, habilidades desbloqueáveis, log de eventos e missões ativas.

Como Usar

1

Clone o repositório

git clone https://github.com/onemapasofficeal/IA-APRENDER-go.git && cd IA-APRENDER-go
2

Execute o GameAI

dotnet run --project GameAI --configuration Release
3

Escolha tema, gênero e complexidade

A IA busca referências na web, gera o jogo e você já pode jogar. Tente temas como "Floresta Sombria", "Espaço Profundo" ou "Castelo Amaldiçoado".
