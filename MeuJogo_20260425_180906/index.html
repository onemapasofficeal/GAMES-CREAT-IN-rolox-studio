Os 3 Apps do Projeto

Cada app é independente e pode ser executado separadamente

🔍

IA-Search

Testador de motores de busca. Consulta 14 buscadores, exibe URLs geradas, testa conectividade HTTP e mostra os resultados encontrados em cada motor.

  • ✓ 14 motores de busca
  • ✓ Teste de conectividade HTTP
  • ✓ Extração de resultados reais
  • ✓ Ranking por velocidade
Ver detalhes →
⭐ Destaque
🏆

Motor de Pesquisa

Agrega resultados de todos os motores em paralelo e usa um algoritmo de ranking inteligente para encontrar o melhor resultado para qualquer pesquisa.

  • ✓ Consulta paralela (14 motores)
  • ✓ Ranking por frequência + posição
  • ✓ Peso por confiabilidade do motor
  • ✓ Barra de pontuação visual
Ver detalhes →
🎮

GameAI

IA que gera jogos completos em segundos, minutos ou horas. Usa o Motor de Pesquisa para buscar referências e cria jogos únicos baseados no tema escolhido.

  • ✓ Geração em 3 velocidades
  • ✓ Combate, exploração, puzzles
  • ✓ Busca referências na web
  • ✓ Jogos únicos por tema
Ver detalhes →

Como Instalar

Precisa apenas do .NET 8 SDK instalado

1

Clone o repositório

git clone https://github.com/onemapasofficeal/IA-APRENDER-go.git
2

Entre na pasta

cd IA-APRENDER-go
3

Execute o app desejado

dotnet run --project SearchEngine.TestApp
dotnet run --project MotorDePesquisa
dotnet run --project GameAI
