O que o IA-Search faz

📋

URLs de Busca

Gera e exibe a URL de pesquisa de cada motor, agrupadas por categoria com descrição de cada buscador.

🌐

Teste HTTP

Testa a conectividade real de cada motor, exibindo código HTTP, tempo de resposta e título da página.

📊

Resultados Reais

Extrai os resultados encontrados em cada motor com URL, título e snippet de cada item.

🏆

Ranking de Velocidade

Classifica os motores por tempo de resposta e exibe um resumo com sucesso/falha de cada um.

🎨

Interface Colorida

Console com cores por categoria: amarelo para principais, roxo para especiais, verde para privacidade.

⚡

Paralelo

Consulta até 4 motores simultaneamente para reduzir o tempo total de teste.

Como Usar

1

Clone e entre na pasta

git clone https://github.com/onemapasofficeal/IA-APRENDER-go.git && cd IA-APRENDER-go
2

Execute o IA-Search

dotnet run --project SearchEngine.TestApp --configuration Release
3

Digite o termo e escolha testar

O app pergunta o termo de busca e se deseja testar a conectividade HTTP. Digite s para testar todos os motores.
